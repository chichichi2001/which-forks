## 原因の見立て

- 問2・問3 の向きのラベル（`*_PREDICTS_G`・`*_G_NEGATIVE`）を、問題を単位にしたブートストラップの区間（パーセンタイル法）で決めていた。この区間は約 80 問の規模ではやや狭く、片側の誤りが 2.5% を少し超えることがある（両側で 6.5% の世界があった）。
- あわせて、400 データで「上側の限界 ≤ 0.045」は、ちょうど 2.5% の正しい検定でも 3 割ほど落ちる厳しすぎる基準だった。

## 変えること（問2・問3 の向きの決め方と、(b) の基準だけ）

1. **向きのラベルは、問題の中の並べ替え検定で決める**：各問題の中で u_F（問3 では m_F）を並べ替える（＝問題の中の中心化した順位を並べ替える）。統計量は T = Σ z_x z_y（D8 の z。並べ替えの下では ρ_w の定数倍）。R = 2,000、SEED_CR3_PERM。片側の p を両方の向きで出す。
2. ラベル（上から順に、最初に当てはまったもの）：
   1. 正の向きの p ≤ 0.025 → `U_PREDICTS_G`（区間の上限が 0.15 未満なら「小さい」と添える）。
   2. 負の向きの p ≤ 0.025 → `U_G_NEGATIVE`。
   3. 区間が −0.15〜+0.15 に収まり、かつ R_w ≥ 0.5 → `U_G_NEGLIGIBLE`（第4版と同じ）。
   4. それ以外 → `U_G_ASSOCIATION_NOT_SHOWN`。
   - 問3 も同じ（`M_*`）。値と区間（ρ_w と問題を単位にしたブートストラップの 95% 区間）は第4版のまま出す。
3. 並べ替え検定は「問題の中で u と g が無関係」という仮説そのものを調べるので、5% の誤りが作りの上で守られる（問題どうしの差の影響も受けない）。
4. **人工データ (b) の基準**：それぞれの世界で 2,000 データ、`*_PREDICTS_G`・`*_G_NEGATIVE` の割合の片側 95% の上側の限界 ≤ 0.04 で合格。

変えないもの：問1、D1〜D8、予算、段、ほかの副次、乱数種。
