## 3. 読み方
1. **重みづけ（主1）は、別の系列のモデルでも再現した。**
   - ゲートに書いたとおり、主1 は仕組みの上でほぼ必ず確認になる。なので「再現の確認」として控えめに書く。
   - 差の大きさは DP4 とほぼ同じ（+0.535 → +0.557）。
2. **逆向き（主2）も再現し、DP4 より強い**（0.378 → 0.286）。迷いの大きい位置ほど、2番目の候補に入れ替えたときの影響は小さい。これがモデルの系列をまたいで見えた。
3. **逆向きは数字の語から来ている（主3）。DP4 では事後の読み（S8）だったものを、事前登録で確認した。**
   - 数字の位置は全体の 20% だが、影響の大きい位置（top e）の約 64% を占める。
   - 数字を除くと、エントロピーの AUROC は 0.286 から 0.452 に上がる。区間 [0.327, 0.583] は 0.5 をまたぐ。
   - 注意：数字以外の位置で両方のラベルがある問題は17問しかない。なので「数字以外では関係がない」とは言えない。言えるのは「**逆向きの大部分は数字の語から来ている**」まで（ラベルの範囲）。
4. **話の筋は、DP4 のまま変わらない。別のモデルで確かめられた。**
   - (a) 強制入れ替えの影響は、迷いの小さい数字の語で大きい（DP3 主2、DP5 主3 で事前登録の確認）。
   - (b) 実際の分かれ道は、「別の語が選ばれる確率」で重みがかかる（DP4 主1、DP5 主1）。
   - 「影響の大きい場所（数字、迷いが小さい）」と「別の語が選ばれやすい場所（迷いが大きい）」がずれている。それが、定義によってエントロピーとの関係が逆になる原因。この構図が、OLMo-2 1B と Gemma-2-2b-it の両方で成り立った。
5. **事後の読み（主張にはしない）**：
   - S5 で見ると、逆向きと「数字のせい」は、**正解した問題に集中**している（主2 0.151、主3 +0.285）。不正解の問題では、逆向きは弱く（0.420）、数字を除いたときの差もはっきりしない（+0.041）。
   - ひとつの読み：正しく解けている推論では、答えを決める数字の語に「迷いは小さいが、変えると答えが壊れる」位置が集まる。間違える推論では、影響の大きい位置が数字以外にも散らばる。
   - これは仮説の出どころとして記録するだけ。確かめるなら次の事前登録で行う。
6. **方法の教訓（S1）**：層別の測り方は、Gemma ではさらに効いた（d_s の半分どうしの相関 0.68）。本数を増やすより、測り方を分けるほうが効く、という DP4 の教訓が強まった。
