- **読み方**：同じ位置・同じ引き直しの記録の中で、「影響そのもの」で選ぶか「p2 で重みづけした影響」で選ぶかだけで、エントロピーの AUROC が 0.44 → 0.71 に変わり、DP1 と DP2 の差（0.43 → 0.66）をほぼそのまま再現した。**逆転の大部分は、引き直しの分かれ道が「2番目の候補が選ばれる確率」で重みづけされていること（エントロピーは p2 とほぼ同じ量）で説明できる。**
- **論文への含み（正直に書くこと）**：DP2 の主1（エントロピーが本当の分かれ道を 0.66 で見分ける）の多くは、分かれ道の定義そのものに p2（＝エントロピー）が入り込んでいるから、という可能性が高い。「エントロピーは分かれ道の良い目印」と強く言うのではなく、「引き直しの分かれ道は、定義上、迷いのある位置で起きやすい。一方、影響の大きさ自体はエントロピーと関係しない（むしろ逆）」と書くのが正確。限界：20問・8本ずつ・2番目の候補だけの近似。

## A：DP2 の S3（同じ区間での比較、2026-10-07 13:2x JST）
ノートブック `DECISION_POINTS/DP2X2_FLIP.ipynb`（実行コード `2d0c806`、CPU）。結果 `reports/dp2x2_A_RESULT.json`（result_sha256 が再計算と一致）。1296 区間、本当の分かれ道 85、強制入れ替えの分かれ道 420。

- **A3（数字）**：区間の頭が数字の語の区間（144）では、強制入れ替えで答えが変わる割合が **62%**（数字でない 1152 区間では 29%）。数字の語のエントロピーは平均 0.16（数字でない語は 0.41）。本当の分かれ道の割合は 9.7% と 6.2% で、差は小さい。
- **数字を除くと**、位置 t のエントロピーは強制入れ替えの分かれ道を **0.609** [0.559, 0.658] で見分ける（順向き）。本当の分かれ道は 0.470。
- A4（重なり）：両方 31、本当だけ 54、強制だけ 389、どちらでもない 822。

### 読み方
- **同じ区間で比べても、区間の最大エントロピーは本当の分かれ道のほうをよく見分ける（差 +0.12、区間が 0 を含まない）。** ただし強制入れ替えは 0.54 で、DP1 のような「逆向き」（0.43）にはならなかった。DP1 の逆向きは、全部の位置で入れ替えた DP1 と、8 トークンおきの区間の頭だけで入れ替えた DP2 の違いもありうる。
- **区間の頭の1語のエントロピーは、どちらもほぼ見分けない（0.47・0.48）。** DP2 の主1の 0.66 は、区間の8語の中のどこかで迷いが大きいことから来ていて、本当の分かれ道は区間の頭ではなく途中で起きることが多いと考えられる。
- **強制入れ替えの「壊れやすさ」は数字の語に集中している**（62% vs 29%）。数字の語はエントロピーが低いので、数字を混ぜるとエントロピーとの関係が下がり、数字を除くと順向き（0.61）になる。Candussio ほか（2026）の「数学の CoT では数字の語のエントロピーが低い」と同じ構図。

## まとめ（A と B を合わせて。事後の探索）
- 強制入れ替えと引き直しで、エントロピーとの関係が変わる理由は、少なくとも2つある。
  1. **重みづけ**（B）：引き直しの分かれ道は「2番目の候補が実際に選ばれる確率（≒エントロピー）」で重みづけされている。同じ位置の記録で、重みづけの有無だけで 0.44 → 0.71。
  2. **数字の語**（A）：強制入れ替えは、エントロピーの低い数字の語を無理やり書き換えて答えを壊しやすい。数字を除くと強制入れ替えでも順向き（0.61）。
- 論文の柱として書けそうな形（DP3 で事前登録して確かめる候補）：「エントロピーが分かれ道の目印になるかどうかは、分かれ道の決め方で決まる。強制入れ替えは数字の語の壊れやすさを拾い、引き直しは迷いの大きさ（＝別の候補の確率）を拾う。どちらも『その位置の選択が答えにどれだけ効くか』とは別もの」。
- 限界：すべて事後。B は 20 問・8 本ずつ・2 番目の候補だけ。A の強制入れ替えは区間の頭の 1 語・貪欲法 1 本。
