## 決めておいた読み方に当てはめると

- 決めておいた分け方では **パターン B（自然な別の語も効く）** にあたる。
  - まれな層（とくに r ≤ 10⁻⁴ の数字）で、e_alt は大きく、e とほぼ同じ。
  - パターン A（自然に引いた語は効かないのに、強制すると壊れる）は見えなかった。
- **見たあとの解釈（決めておいた読み方の外）**：
  - CR-5 と DP の「食い違い」の大部分は、**層の違い**で説明できそう。
    - DP で答えが壊れるのは、r ≤ 10⁻⁴ のとてもまれな層の数字の位置。
    - CR-5 が試せたのは、48 本で 1〜2 本出る（r ≈ 0.02）層の単語だけ。その層では DP でも効き目は小さく、CR-5 の結果と矛盾しない。
    - DP の「壊れやすい層」にあたる単語は、CR-5 で 48 本でも揺れなかった 299 語の中にあると考えられ、まだ試していない。
  - 「自然か強制か」は、2 番目の候補までなら効き目をほとんど変えない。確率 10⁻⁶ まで下げると、少しだけ多く壊れる。

## 限界

- e_alt は「土台の語を除いた分布から 1 語引いたもの」。とてもまれな層では、引かれる語の多くは 2 番目の候補そのものかもしれない（e − e_alt ≈ 0 はそれでも説明できる）。どの語が引かれたかの一致は、今回は見ていない。
- まれな層の数字の位置は、層によっては数が少ない（3〜17 位置）。区間が広い。
- モデルは 1B と 2B の 2 つ、データは GSM-Symbolic だけ。CR とは単位（トークンと単語）も違う。
