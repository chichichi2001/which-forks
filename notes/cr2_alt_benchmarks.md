# CR-2 の代わりのベンチマークの候補（G-L が得られなかったときの備え）

PRIVATE UNPUBLISHED RESEARCH.

- 2026-10-13 19:1x〜19:4x JST、オーナーの依頼（「最悪ライセンスの作者がだめなこともあるかもだから、もう一度代替ベンチマークを探したほうがいいかも？」19:09 JST）を受けて調べた。
- 見たのは、データの説明（カード・論文の要旨・リポジトリのページ）とライセンスの表示だけ。**問題の中身は見ていない。** API にも何も送っていない。
- ライセンスは、2026-10-13 時点のページの表示を書き写したもの。使う前に、固定する版のライセンスをもう一度確かめる（CR-2 の G-L と同じ扱い）。

## 条件

1. ライセンスがはっきりしていて、研究での利用・外部 API への送信・数の公表ができる（MIT・Apache・CC BY など）。
2. 答えが数で読める（`#### <数>` の形にできる）。
3. Claude Haiku 4.5 で答えが割れる難しさ（正答率 0.3〜0.7 くらい）。難しさを調節できると良い。
4. 解き方の長さがほどほど（CR-2 の土台の道の条件は 40〜300 単位）。
5. これまでの下見・実験で使っていない。

## 向かないもの

- **GSM-Plus**（CC BY-SA 4.0）：GSM8K を少し変えたもの。Haiku 4.5 には易しすぎる見込み。
- **MathCAMPS**：Claude 3 Haiku でも全体 84% と易しい。リポジトリのライセンスの表示を確かめられなかった。
- **GSM-Symbolic**：CR-1・DP で使ったもので、下見 1 で P1・P2 も易しすぎた。ライセンスの表示は **CC BY-NC-ND 4.0**（非営利・改変したものの配布はしない）。これまでの使い方（研究のため、問題文を配布しない）は、この表示の範囲に入ると読めるが、論文に書くときは表示を引用しておく（メモ）。

## 使うときの流れ（案）

- G-L が「だめ」か、10/27 の時点で返事がなければ、オーナーと相談する。
- 候補 1（CHASE-Math）と 2（MATH Level 5 の整数）を、下見 2 と同じ形の小さな下見（それぞれ 30〜50 問、$1〜2）で比べ、正答率と答えの割れ方を見る。下見の計画は送る前に書く。
- どちらも合わなければ、3（自前の生成器）を作る。
- データを変えたら、CR-2 の計画は「データ」の節を書き直して、もう一度レビューを受ける（探す段・確かめる段・分析の決まりはそのまま使える）。
