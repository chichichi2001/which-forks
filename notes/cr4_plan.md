## 0. この実験で何を確かめるか（と、確かめないこと）

CR-3 で分かったこと：

- CR-2 の分かれ道のラベルは、別の単語を書かせたときに答えが変わりやすい単語と重なっていた（問1、AUROC 0.818）。
- 別の単語が出た 264 語の中では、「別の単語が出る割合」m も「最初の単位の迷い」u も、書かせたときの差 g との順位のつながりを示さなかった（問2・問3）。

CR-2 の分かれ道の見つけ方は「揺れの多さ × 揺れたときの効き目」（d_s = m × g）で、**揺れなかった単語は最初から候補にならない**。もし m と g が本当に関係しないなら、CR-2 で 18 本中 1 本も揺れなかった単語（340 語）の中にも、**書かせれば答えが変わる単語**（隠れた分かれ道）があるはず。CR-4 は、この 340 語について

1. 新しく 32 本引いて別の単語を探し（発見）、
2. 見つかった単語では一番多い別の単語を書かせて引き直し（書かせ）、
3. 書かせたときの差 g_F を、CR-3 の 264 語（揺れた単語）の g_F と比べる。

- **確かめないこと**：別の問題・別のモデルへの一般化（同じ 90 問・同じ 604 語）。32 本引いても別の単語が見つからなかった単語は、書かせる別の単語がないので**試さない**（数を報告する。「隠れた分かれ道がない」とは書かない）。
- ②の探索（9.）は CR-4 の判定に使わない。結果は「探索」と書く。

## 2. 定義

- **E1 揺れなかった単語 NW**：CR-2 の確かめる単語 604 語のうち、CR-3 の W（264 語、`notes/cr3_lock_stageA.json`）に入らない単語。凍結したコードで作り直す（340 語、89 問。違えば止まる）。
- **E2 発見の切れ目**：NW の各単語 v の切れ目 v − 1。
  - CR-3 で U として 32 本引いた切れ目（C_W に入るもの、78 個）は、**CR-3 の応答をそのまま使う**（同じモデル・同じ頼み方・同じ設定で引いた独立の応答なので、新しく引いたものと同じ扱いができる。CR-3 の段B の記録のハッシュで照合）。
  - それ以外（262 個）を段B1 で新しく 32 本ずつ引く（K_D = 32 で固定、CR-3 と同じ）。
- **E3 別の単語 a1(v)**：切れ目 v − 1 の 32 本のうち、新しい定義 10 で s_v を書かなかった応答の最初の単位（定義 14）を、CR-3 の D3 と同じ決まりでまとめた 1 番目（本数の多い順、同数は sha256 の小さい順。プリフィルの文字列はそのまとまりで一番多い元の形）。a2 は使わない。
  - a1 がない単語（揺れが 0 本、または揺れた応答がすべて空・空白だけ）は「試さない」として数える。
  - 使う応答は k = 0〜31 のうち戻ってきたものすべて（分母は戻ってきた本数）。NW では a1 はたいてい 1〜2 本しか出ず、同数のときは sha256 の順で決まる（本数の多さではなく決まりで選ばれる）ことを結果に添える。
  - **見た目だけの書き換えの目印**（自動、数だけ）：a1 と s_v を、小文字にして英数字以外を取り除いたものが同じなら「見た目だけ」（例：句読点・マークダウン・大文字小文字の違い）。感度の分析（4. S9）に使う。
  - 記録に文字列・1 語ずつの sha256 は書かない（CR-3 の D3 と同じ）。全部のプリフィル文字列をまとめた 1 つの sha256 と、目印の数だけ。
- **E4 試す単語 T**：a1 がある NW の単語（6. の予算の決まりで外れたものを除く）。
- **E5 条件**（段B2）：
  - **A1(v)**：プリフィル P_{v−1} + a1(v)。本数 K2。
  - **U(v)**：プリフィル P_v（元の単語を書いたあとの続き）。q_O に使う。切れ目 v が CR-3 の C_W にある → CR-3 の応答（32 本）を使う。段B1 の切れ目にある → 段B1 の応答（32 本）を使う。どちらにもない → 段B2 で K2 本引く。
  - **K2 の決め方**：段B1 が終わった時点で、件数と段B1 で実際に使った額だけから、{64, 48, 32, 24, 16} のうち 6. の段B2 の予算の確かめを通る**一番大きい値**。どれも通らなければ K2 = 16 にして、T の候補の単語を sha256("CR-4|{ID}|{v}") の小さい順に 1 語ずつ（その単語に新しい U(v) が要ればその分も足して）確かめの式に入れ、**最初に通らなくなった単語の手前までを入れる**（それより後は飛ばさずに全部外す）。外れた単語は数を報告し、未完了には数えない。応答の中身は見ない決め方。
  - 使い回した切れ目（CR-3・段B1 の 32 本）は、K2 > 32 でも足さない。
  - **ずれの確かめ（ドリフト）**：予算の決まりを当てる**前の** T の候補（a1 がある NW の単語すべて）の U(v) のうち CR-3 の応答を使い回すものから、sha256("CR-4-drift|{ID}|{c}") の小さい順に 20 個（足りなければ全部）を選び、段B2 で 32 本ずつ引き直す（約 640 件、$0.33）。**その額を先に確保してから** K2 と単語の入れ方を決める。custom_id は**専用の種類 4**（code = 4000 + c）にして CR-3 の custom_id と重ならないようにする。分析には使わず、使い回した q と新しい q の差を記述する（S10）。
- **E6 単語ごとの量**（分母は戻ってきた本数）：
  - q_O(v)：U(v) の「変わった」割合。q_A1(v)：A1(v) の「変わった」割合。**g_F(v) = q_A1(v) − q_O(v)**（CR-3 と同じ）。
  - m_F(v)：切れ目 v − 1 の 32 本のうち s_v を書かなかった割合。
  - 偶数・奇数の本番号で半分に分けた g_F_h0・g_F_h1（信頼性用、CR-3 と同じ）。
- **E7 欠け**：1 つの条件で 2 回の出し直しのあとも K 本中 ⌈0.875 K⌉ 本未満しか戻らなければ欠け（**K はその条件ごとの本数**：使い回した U は 32、段B1 は 32、段B2 の A1・U は K2。CR-3 の関数は 1 つの K しか持たないので、CR-4 では条件ごとに K を持つ関数を新しく書く）。欠けた条件を使う量は NA、補わない。発見の切れ目が欠けた単語は「試さない」に数える（欠けとして別に数える）。
- **E8 CR-3 の 264 語の量**：CR-3 の段C と同じ関数（`pork.cr3.word_quantities`）で作り直した g_F（K_F = 32）。CR-3 の結果の数と一致することを確かめる（Q1 の観測 AUROC が 0.8181… と一致しなければ止まる）。

## 3. 問いとラベル

区間は、問1 の Δ（d_i の t の区間）を除き、**問題を単位にした**ブートストラップ（2,000 回、SEED_CR4_BOOT）の両側 95%。並べ替えは R = 2,000、SEED_CR4_PERM。

- **問1（主。揺れなかった単語の効き目は、揺れた単語より小さいか）**
  - 対象：T の単語のうち g_F が定義されるものが 1 語以上**かつ** W の単語のうち g_F が定義されるものが 1 語以上ある問題。
  - 値：問題ごとに d_i =（NW の g_F の平均）−（W の g_F の平均）、Δ = d_i の問題平均（n 問）。
  - 区間：d_i の **t の区間**（Δ ± t_{0.975, n−1} × sd(d_i)/√n）。d_i は問題ごとに独立なので、問題を単位にした区間になる（パーセンタイルのブートストラップは修正 1 で狭すぎたため使わない）。
  - 向きの検定：統計量は **t = Δ / (sd(d_i)/√n)**（NW と W で雑音の大きさが違っても崩れにくいように、標準誤差で割る）。問題の中で NW / W の目印を並べ替え（その問題の NW の数は保つ）、そのたびに d_i と t を計算し直す。p（NW が大きい向き）= (1 + #{null ≥ t_obs}) / (1 + R)、p（小さい向き）= (1 + #{null ≤ t_obs}) / (1 + R)。並べ替えの回で sd(d_i) = 0 なら、その回の t は Δ の符号どおり ±∞（Δ = 0 なら 0）とする。
  - ラベル（**上から順に、最初に当てはまったもの**）：
    1. 対象の問題が 20 未満 → `Q1_INSUFFICIENT`。
    2. p（NW が大きい向き）≤ 0.025 → `NW_EFFECT_LARGER`。
    3. p（NW が小さい向き）≤ 0.025 → `NW_EFFECT_SMALLER`。
    4. t の区間が −0.05〜+0.05 に収まる → `NW_EFFECT_SIMILAR`。
    5. それ以外 → `NW_EFFECT_DIFFERENCE_UNDETERMINED`。
  - 読み方：
    - SMALLER：揺れの少ない単語は、書かせても答えが変わりにくい。「揺れの多い・少ないの両端で m と g が分かれることと**矛盾しない**」と書く。NW と W は、別の単語の見つけ方（32 本と 18 本）・別の単語の珍しさと種類・位置も違うので、m だけのせいとは書かない（CR-3 の問3 は揺れた単語の中だけの話なので矛盾しない）。
    - SIMILAR・LARGER：揺れの少なさは、**書かせたときの**効き目の小ささを意味しない。「揺れを観察する見つけ方（CR-2 の d_s = m × g）は、書かせれば効く単語を見落としうる」と書く。ただし自然に引いたときの答えのばらつきへの寄与は m が小さいぶん小さいことを添える。
    - どの場合も、比べているのは「32 本の中で別の単語が見つかった」NW の単語だけ。NW の別の単語は 32 本中 1〜数本しか出ないまれな単語で、W の a1 より「珍しい」書き換えであることを添える。
- **問2（主。隠れた分かれ道は 1 つでも確かめられるか）**
  - 値：T の各単語で、A1(v) と U(v) の「変わった」本数を 2×2 の表にし、**片側のフィッシャーの正確検定**（A1 のほうが変わりやすい向き）の p。**g_F が定義される T の単語すべて**（予算で外れた単語・欠けた単語は入れない）を 1 つの家族として**ホルムの方法**（家族の有意水準 0.05）で補正し、残った単語の数 H。
  - ラベル：T の g_F が定義される単語が 20 未満 → `Q2_INSUFFICIENT`。H ≥ 1 → `HIDDEN_FORKS_FOUND`（H を書く）。H = 0 → `HIDDEN_FORKS_NOT_DETECTED`。
  - 物差し（記述、ラベルに使わない）：同じ手順を CR-3 の 264 語に当てた数 H_W（A1 は k < min(K2, 32) の本だけ、U(w) は 32 本。ホルムは 264 語の中で）と、そのうち CR-2 の分かれ道（lab2）の数。「同じ物差しで、揺れた単語では何語が残るか」を並べる。
  - 読み方：ホルムの補正は厳しく、K2 = 32 なら差がおよそ 0.4〜0.5 以上の単語しか残らない。H = 0 でも「隠れた分かれ道はない」とは書かず、「この本数・この厳しさでは確かめられなかった」と書く。

- 問1・問2 は別々の問いで、まとめた主張はしない。多重性の補正は問2 の中のホルムだけ。

### ラベルの優先順（最初に当てはまったもので止める）

1. 段A・段B1・段B2 の前の照合で止まった → `STOPPED_BEFORE_RUN`（どこで止まったかを書く）。
2. 未完了 → `INCOMPLETE_NO_CONFIRMATORY_VERDICT`：予算で止まった、終わりの状態が分からないリクエストがある、発見の切れ目の欠けが NW の 10% を超えた、T の単語のうち欠け（U(v)・A1(v)）で g_F が NA になったものが T の 10% を超えた。

4. 読めない応答 > 20%（CR-4 の段B1・段B2 で新しく引いた全応答。使い回した CR-3 の応答とドリフトの確かめは数えない）→ `READOUT_UNRELIABLE_NO_CONFIRMATORY_VERDICT`。5〜20% はすべてのラベルに `READOUT_CAVEAT`。
