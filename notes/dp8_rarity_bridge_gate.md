## 定義（DP5・DP7 と同じところは短く）

1. **モデル**：［決定1］。おすすめは Gemma-2-2b-it だけ（DP5・DP7 と同じ版・bfloat16・eager attention・同じプロンプト・同じ採点）。
2. **問題**：GSM-Symbolic の算数 40 問。これまでのどの実験とも重ならないもの（凍結時に埋めたことを参照）。
3. **土台の道**：DP7 と同じ。貪欲法で最大 512 トークン。次のものを記録する。
   - エントロピー・p₁・p₂
   - 1 位と 2 位の語
   - w_τ・p(w_τ)・合うかどうか
   - 数字かどうか
   - 答えの先頭 a
4. **位置**：t = 0, 8, 16, …（t < a）。DP5・DP7 と同じ。
5. **4 種類の引き直し**（温度 1.0、各 32 本、まとめて計算）：
   - **keep**：t の語を 1 位 w₁ に決めてから引く。
   - **swap**：t の語を 2 位 w₂ に入れ替えてから引く。
   - **alt**：t の語を、w₁ を除いて正規化し直した分布から引き、そのあとを引く。DP4・DP5 と同じ引き方。どの語が引かれたか（語の番号）も記録する。
   - **swapt**：t の語を w_τ（確率が 10⁻⁶ に一番近い語）に入れ替えてから引く。DP7 と同じ。
6. **量**：
   - r = 1 − p₁（その位置で土台の語以外が出る確率）
   - e₂ = q_swap − q_keep
   - e_alt = q_alt − q_keep
   - e_τ = q_swapt − q_keep
   - d_s = r × e_alt（その位置が自然な答えのばらつきに寄与する量）
   - q は、土台の答えと違う答えになった割合（DP5・DP7 と同じ。読めない答えも「違う」に数える）。
7. **層**：r の 6 層。境目は 10⁻⁴・10⁻³・10⁻²・0.05・0.2。境目と同じ値は下の層に入れる。DP8-X と同じ。
8. **数字の位置**：DP5・DP7 と同じ（土台の道の t の語が数字を含む）。
9. **区間**：すべて、問題単位のブートストラップ 2,000 回の両側 95%（パーセンタイル）。

## 問い（主）と判定（事前に決めるラベル）

主の問いは 4 つ。それぞれ別のことを問うので、多重比較の補正はしない（DP5・DP7 と同じ扱い）。主張は、このラベルと数字の範囲に限る。

- **主1（自然に引いた別の語は、2 番目の候補と同じくらい効くか）**
  - 量：全位置での e₂ − e_alt の平均（位置で重みをつけた平均。区間は問題を引き直す）。
  - 同じとみなす幅：±δ（［決定2］。おすすめ δ = 0.03）。
  - ラベル：
    - 区間が −δ〜+δ の中に入る：`NATURAL_LIKE_SECOND`
    - 下限 > +δ：`SECOND_HURTS_MORE`
    - 上限 < −δ：`NATURAL_HURTS_MORE`
    - それ以外：`NATURAL_VS_SECOND_UNDECIDED`
- **主2（別の語が出にくい位置ほど、自然に引いた別の語の効き目は大きいか）**
  - 量：問題ごとに、位置の r と e_alt のスピアマン相関を出し、問題で平均。位置が 4 つ以上あり、r と e_alt のどちらも一定でない問題だけを使う。
  - ラベル：
    - 上限 < 0：`RARER_ALT_HURTS_MORE`
    - 下限 > 0：`RARER_ALT_HURTS_LESS`
    - それ以外：`RARITY_ALT_UNDECIDED`
- **主3（まれな位置は、自然な答えのばらつきにほとんど寄与しないか）**
  - 量：S_rare = r ≤ 0.05 の位置の d_s の合計 ÷ 全位置の d_s の合計。区間は、引き直した問題での合計の比。
  - 線：θ（［決定3］。おすすめ θ = 0.10）。
  - ラベル：
    - 上限 < θ：`RARE_POSITIONS_CONTRIBUTE_LITTLE`
    - 下限 > θ：`RARE_POSITIONS_CONTRIBUTE`
    - それ以外：`RARE_CONTRIBUTION_UNDECIDED`
  - 読めない場合：全位置の d_s の合計が 0 以下、または引き直しの 5% 超で合計が 0 以下なら `RARE_CONTRIBUTION_NOT_READ`（比が意味をなさないため）。合計が 0 以下の引き直しは数を報告し、区間からは除く。
- **主4（確率 10⁻⁶ の語は、2 番目の候補より多く壊すか）**
  - 量：合う位置（DP7 と同じ定義）での e_τ − e₂ の平均。
  - ラベル：
    - 下限 > 0：`TAU_HURTS_MORE_THAN_SECOND`
    - 上限 < 0：`TAU_HURTS_LESS_THAN_SECOND`
    - それ以外：`TAU_VS_SECOND_UNDECIDED`
- **全体にかかる線**：
  - ガード：土台の道の正解率 0.20〜0.90。外れたら `DP8_NON_DISCRIMINATING`（ラベルは出さない）。
  - 合わない位置が全体の 10% を超えたら `DP8_MATCH_COVERAGE_LOW` と記録し、主4 の読み方を弱める（ラベルはそのまま出し、結果ノートに「合う位置だけの比較なので、偏りが入っているおそれがある」と必ず添える）。
  - 事後再生監査で、ずれた問題が 2 問以上なら `DP8_PROTOCOL_FAIL`（ラベルは出さない）。
  - ガードや監査で止まったときも、集計の値は RESULT に残す（DP7 と同じ）。そのときのラベルは FINAL のもの（`DP8_NON_DISCRIMINATING` か `DP8_PROTOCOL_FAIL`）だけで、RESULT の中の仮のラベルは読まない。

- **モデル**：`google/gemma-2-2b-it`、版 `299a8560bedf22ed1c72a8a11e7dce4a7f9f51f8`（DP5・DP7 と同じ）、bfloat16、`attn_implementation="eager"`。プロンプト・答えの読み取り・採点は DP5・DP7 と同じ。
- **種**：
  - テンプレートの選び方 202610151601
  - 問題 202610151602
  - keep の乱数列 202610151603
  - swap の乱数列 202610151604
  - alt の乱数列 202610151605
  - swapt の乱数列 202610151606
  - 監査 202610151607
  - ブートストラップ 202610151608
  - 本番前の確認の合成 logits 202610151609
- **問題の選び方**：
  - テンプレートは `sorted(random.Random(202610151601).sample(range(100), 40))`。行はこの番号の順。
  - 各テンプレートで、CR-1 と同じ除外の鎖（`pork/cr1_items.chain_and_candidates`）をたどる。この鎖で除かれるのは次のもの。
    - Q3-A・Q3-B・Q4-A・Q4-B・Q5・Q6S・Q8T
    - DP1
    - DP2 または DP3
    - DP4・DP5・DP7（それぞれの 40 個に入っていれば）
  - そのあと、CR-1 の候補（テンプレートごとに最大 3 問。PARA-1a も同じ候補を使った）をすべて除く。
  - 残り（データの中の並び順のまま）から `random.Random(202610151602 + テンプレートid).sample(残り, 1)` で 1 問。残りが 0 なら止める。
  - 作り直した CR-1 の候補の一覧は、CR-1 の凍結した一覧（段2 の sha256 `b6f6375a…`、`pork/cr1_run.py`）と一致することを確かめる（違ったら止める）。
  - データの版は DP2〜DP7 と同じ。これまでのすべての問題と CR-1 の候補に重ならないことを、トークンを作る前に確かめる（重なったら止める）。
- **w_τ の選び方**：DP7 と同じ（`pork/dp7_matched.tau_choice`。τ = 10⁻⁶、合う範囲は ±0.5 桁）。
- **alt の引き方**：DP4・DP5 と同じ（`alt_sample`：w₁ を除いて正規化し直した分布から、その位置の 1 本目の乱数で引く）。2 語目からは素のサンプリング。引いた最初の語の番号を 32 本とも記録する。
- **引き直し**：DP5・DP7 と同じ作り。
  - 温度 1.0 の素のサンプリング。EOS か合計 512 トークンで止める。32 本をまとめて一度に計算する。
  - j 本目の乱数列は `random.Random(種 + (行+1)×1,000,003 + (i+1)×10,007 + j)`。
  - swap・swapt で、入れた語が終わりの記号なら、続きは空。
  - alt で引いた最初の語が終わりの記号なら、その本はそこで終わる（DP4・DP5 と同じ）。
- **e_alt_not2（S2）**：alt の 32 本のうち、最初の語が w₂ と違う本だけで数えた q から q_keep（32 本）を引く。該当する本が 0 本の位置は除き、数を報告する。
- **平均と区間**：
  - 平均は、位置で重みをつけた平均。
  - 区間は、位置が 1 つ以上ある問題（N 個。土台の答えが読めない問題は位置がないので、正解率にだけ入る。DP7・DP8-X と同じ）の番号を `numpy.random.default_rng(202610151608)` で N 個ずつ復元抽出（2,000 回）し、引いた問題の位置をつなげて量を計算する。同じ引き直しの組を、すべての量に使う。
  - 区間の端は DP7 と同じ順序統計（`pork/dp1x_probe._ci`）：使える値を小さい順に並べ、n 個のとき下は ⌊0.025n⌋ 番目、上は ⌊0.975n⌋ − 1 番目（0 から数える）。
  - 区間に使えない引き直し（その量の位置がない、など）が半分を超えたら、区間は「なし」とし、ラベルは「決まらない」にする。
- **主2 と S4 のスピアマン**：同じ値の順位は平均の順位にする（DP8-X と同じ実装）。
- **主3**：比の点の値と、引き直しごとの比。全位置の合計が 0 以下の引き直しは区間から除き、数を報告する。それが 5% を超えるか、点の値の合計が 0 以下なら `RARE_CONTRIBUTION_NOT_READ`。
- **本番前の確認の線**：DP5・DP7 と同じ。合成の logits（語彙 2,000 と 256,000、同じ値の語を含む）で、GPU と Python の実装が次の 4 つすべてで一致すること（不一致 0）。
  - 迷いのサイン
  - 素のサンプリング
  - alt の最初の語
  - w_τ の選び方
- **ガード**：土台の道の正解率 0.20〜0.90。外れたら `DP8_NON_DISCRIMINATING`。
- **監査**：
  - `random.Random(202610151607).sample(range(40), 5)` で 5 問。
  - 各問で位置を 3 つ（DP7 と同じ選び方）。
  - 土台の道（w_τ を含む）と、keep・swap・alt・swapt の j = 0〜3 を参照の実装で作り直す。

    - 語彙 256,000・同じ値の語を多く含む合成の logits で、不一致 0 を確かめてある（`notes/dp5_runtime_optimization_candidate.md`、`tests/test_dp5_fast_reference.py`）。
