# 結果：CHASE-Math に寄せた作り物の世界での S2 の見つける力

PRIVATE UNPUBLISHED RESEARCH.

- **探索（ラベルなし）。** 決まり：`notes/cr2_chase_power_plan.md`（5ea5f1a、計算の前）と、その追補（5cab6e1、N = 150 の計算の前。N = 90・62 の結果は見たあと）。
- スクリプト：`scripts/cr2_chase_power.py`。出力：`reports/cr2_chase_power.txt`（N = 90・62）、`reports/cr2_chase_power_n150.txt`（N = 150）。API・データの中身は使っていない。
- 世界：道の長さ 41〜159、道の初めの変わる割合 q0 の平均 0.26（下見 3 の CHASE-Math）。探す段は共通の関数（S2）。1 問あたり 約 463 件。

- 主1 の対象の問題：N = 62 で 約 41、90 で 約 60、150 で 約 101。C2 の信頼性は分かれ道 3 で 0.74、10 で 0.30。

## 読み方（計画の目安に照らして）

1. **陰性対照**：差なしの世界はすべて合格。分かれ道 3 の世界は入口をほぼ必ず通り、`BEYOND_*` は名目の 5% 前後（0.054）。
2. **N = 90**：分かれ道 3 で 0.275（0.2 以上）、10 で 0.155（0.2 未満）。目安の「その間 → オーナーと相談」。
3. **N = 150**（追補の目安「両方 0.2 以上なら N を増やす案を勧める」）：分かれ道 3 で 0.420 と上がったが、10 では 0.110 で上がらなかった（N = 90 の 0.155 との差は 200 データの揺れの範囲）。目安のとおり、**N を増やす案は勧めない**（両方が 0.2 以上ではないため）。
4. 見立て（事後）：分かれ道が少ない世界では、N を増やすと見つけやすくなる。分かれ道が 10 個の世界では、1 つの窓が当てるのは 10 個のうちの一部だけで、確かめる単語の中の「相対的な分かれ道」がまぎれやすく、N を増やしても伸びにくいようだ。
5. GSM-Infinite を想定した世界（q0 0.3、62 問）の 0.195・0.065 と比べると、CHASE-Math に寄せた世界（q0 0.26、90 問）の 0.275・0.155 は同じか少し良い。データを移しても、見込みが悪くなることはなさそう。
6. どの数も、本物の Haiku 4.5 の見つける力ではない。
