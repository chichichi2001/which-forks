## 3. 読み方（ゲートの範囲で）

1. **「定義の逆転」は、3 つ目の系列・7B の大きさでも再現した。**
   - 強制入れ替えの効き目はエントロピーの小さい位置に集まる（主1 0.259）。
   - 別の語が選ばれる確率で重みをつけると、向きがひっくり返る（主2 +0.506、主2b 0.745）。
   - 逆向きの大部分は数字の語から来ている（主3 +0.226）。数字以外の位置だけでは 0.485 で、0.5 をまたぐ。
   - OLMo-2 1B・Gemma-2-2b-it・Qwen2.5-7B-Instruct の 3 つで、同じ向き・同じくらいの大きさになった。
2. **「まれさの橋渡し」も、3 つのうち 2 つは再現した。**
   - 自然に引いた別の語は、2 番目の候補を入れたのと同じくらい効く（主4、差 +0.001）。
   - 別の語が出にくい位置ほど、出たときによく効く（主5 −0.319）。
3. **まれな位置の寄与（主6）は、決まらなかった。**
   - 点推定（5.4%）は Gemma（−0.2%）より大きく、そのほとんどは 0.01〜0.05 の層から来ている。
   - ただし区間は 0 をまたぎ、上の端が 10% を越えた。原因は、まれでない層の位置が少ないこと（7B は迷わない）と、d_s の信頼性が低いこと（S1、0.14）。
   - 言えるのは「ばらつきの大部分（約 95%）は r > 0.05 の位置から来る」まで（S6、記述）。「まれな位置は 10% 未満しか寄与しない」は、7B では言い切れない。
4. **主2b の注意**：top d_s の境目は 2.9×10⁻⁷ で、とても小さい。7B では d_s がはっきり 0 でない位置が少ない。そのため top d_s のラベルは、実際には「再サンプリングで少しでも答えが揺れる位置か、まったく揺れない位置か」に近い分け方になっている。それでも順向き（0.745）は線から遠く、並べ替えの対照（S9）の範囲の外にある。
5. **事後の読み（主張にはしない）**：
   - 7B では、確率をそろえられる位置（S12）がちょうど「逆向きのない半分」になっていた。逆向きが数字の位置に集まっている、という主3 と同じ絵を、別の切り口から見た形になる。
   - 大きいモデルほど自信の強い位置が増え（S2：59%）、まれな位置の効き目は小さくなった（数字の位置の e_alt 0.485 → 0.300）。2 モデルだけの比較なので、大きさとの関係としては読まない。

- 3 つのモデルは問題が違うので、モデルのあいだの差は検定していない。
