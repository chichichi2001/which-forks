## 読み方（ゲートの範囲で）

1. **まれな別の語は、出たときには大きく効く。** 別の語が出る確率が 1 万分の 1 以下の位置では、数字を別の語にすると、答えが変わる割合が約 0.5 増えた。
   - これは「無理やり入れたから」ではない。自然に引いた別の語でも、2 番目の候補を入れたのと同じくらい効いた（主1）。2 番目の候補以外の自然な語でも同じだった（S2）。
2. **ただし、まれな位置は普段の答えのばらつきをほとんど作らない**（主3）。出ないからである。ばらつきのほぼすべては、別の語が 5% 以上の確率で出る位置から来ている。
3. **確率 10⁻⁶ の語は、2 番目の候補より少しだけ多く壊す**（主4、+0.03）。差は小さい。
4. **CR-5 との橋渡し**（ゲートが言う範囲の外の解釈。単位・モデル・データが違う）：
   - CR-5 で試せた「48 本に 1〜2 本出る」層は、DP8 では 0.01〜0.05 の層にあたる。DP8 でもこの層の効き目はほぼ 0 で、CR-5 の結果と合う。
   - CR-5 と DP3〜DP7 の食い違いは、「自然か強制か」ではなく、**どのくらいまれな位置を見ていたか** の違いで説明できる。
   - 開いたモデルで答えが壊れやすい「とてもまれな数字の位置」にあたる単語は、CR-5 で 48 本でも揺れなかった 299 語の中にあると考えられる。観察した揺れからは、原理的に見つけにくい。

## 限界

- モデルは 1 つ（Gemma-2-2b-it）、課題は算数（GSM-Symbolic）だけ、単位はトークン。
- まれでない層の数字の位置は少ない（2〜6 位置）。そこでの数字の値は読まない。
- 主3 の比は、全体の合計（1.61）が小さくはないので計算できた。ただし、r ≤ 0.05 の層の合計は正負が打ち消し合ってほぼ 0 になっている。
