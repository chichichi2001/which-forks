- **W2（Q3-R）**：結果が分からない create のあとは、印が開いている間は何も送らない。一覧で 0 件なら印を残して探し続け、30 分見つからなければ止めてオーナーに渡す（オーナーが Console で確かめ、印の正確な時刻を入れたときだけ消せる）。1 件なら「未確認」として採用し、そのバッチが終わって戻った `custom_id` の集合が期待どおりと確かめられるまで新しいバッチを出さない（違えば止まる）。2 件以上なら止まる。試験：最初は一覧に見えず後から見えるとき再送 0、同じ件数の無関係なバッチを採用したら回収で止まる、など。
