  - 候補が 120 行あれば、N の上限 90 には足りる見込み（下見 3 では条件を満たす割合 1.00。48 問なので粗い）。
- **ブートストラップの単位と独立性の仮定**（B4）：
  - 重複の確かめは、同じ文章の完全な重複を除くだけで、**問題どうしの統計的な独立性を示すものではない**。CHASE-Math は、1 つの種の問題から深さを変えて何問も作られうるので、**同じ種を共有する問題どうしには相関がありうる**。

  - 事前に決める感度の確かめ（記述だけ、ラベルなし）：主0・d_s > 0 の割合・主1 の観測の AUROC について、(i) 深さの層（2〜3・4〜5・6〜8）ごとの内訳、(ii) **種を単位にした**ブートストラップの区間、を並べる。(ii) が主の区間より大きく広いときは、主の区間の解釈に「問題どうしの相関がありうる」と添える。種が 2 つ未満・ブートストラップで種が消えて計算できないなどのときは「感度の計算不能」と報告する。(ii) が広がらなかったことを、独立性の証明としては使わない。
  - **種の重なりの数の報告（H3。段2 と G3 で必ず）**：候補 120 問・主の N 問・候補のうち下見 3 の 48 問と種が同じもの、のそれぞれについて、異なる種の数、いちばん大きい種の問題の数、行が 2 つ以上の種の数、種ごとの問題の数の分布、実効的な問題の数の目安 N_eff ＝ N² ／ Σ（種ごとの問題の数）²（種の中で値が完全に同じだったときの、独立な単位の数の目安。記述だけ）を出す。
    - **空の集まり**（I1）：集まりが 0 問なら「該当なし」として、件数 0・異なる種 0・いちばん大きい種 NA・分布 NA・`N_eff = NA_EMPTY` と書く（0 で割らない。「計算不能」とは区別する）。
    - N_eff は、種の中で完全に同じ値をとる場合を想定した、等しい重みの平均についての記述の目安（Kish の形）で、AUROC の正確な有効数でも、区間の被覆の保証でもない（I2）。
  - **(ii) の区間は、主の区間のすぐ隣に必ず並べる**（感度の節に回さない）。(ii) が主の区間より大きく広いとき（目安：幅が 1.5 倍以上）は、要約と結論で、問題を単位にした区間を主に書かず、2 つの区間を並べて「問題どうしの相関がありうる」と添える。
  - **(ii) の計算の決まり**（I2）：種を入れ替えありで引き直し、引いた種に属する**すべての問題をまとめて**戻し、**主と同じ問題の重み**（種の重みではない）で、主と同じ統計量を計算する。引き直しで統計量が定義されない回は、統計量ごとに NA として数え、その数を報告する。
  - 1.5 倍は警告を強める**運用の目安**で、1.5 倍未満だから独立が確かめられた、という境目ではない。主の区間は幅にかかわらず常に「独立の仮定のもと」と書き、(ii) は幅にかかわらず必ず隣に並べる。主の区間の幅が 0 で比が定まらない（0/0 や無限大）ときは、比を NA と記録し、2 つの区間をそのまま並べる。
  - **2 つの別の論点**：主1 の p 値の正しさ（切れ目の中の条件つきの入れ替え。問題どうしの独立を使わない）と、ブートストラップの区間が本当の値を含む割合（問題どうしの独立を使う）は別の論点で、片方の正しさからもう片方を導かない。
  - 種による汚染や重なりがないことは主張しない。

### 4. 探す段と確かめる単語（新しい定義 17・18、［決定G］）

**定義 17：探す段**（1 問ごと。G1b のあと、確かめる段より前）

- **区間の選び方**：隣どうしの格子の落ち幅 D_i ＝ q̂(g_i) − q̂(g_{i+1}) がいちばん大きい区間 [a, b] = [g_i, g_{i+1}] を選ぶ。同点は i の小さい方。落ち幅が 0 以下しかなくても、いちばん大きいものを選ぶ。

### 9. 欠けの扱い（F10）

- **CR-2 の欠けの基準**：使った切れ目で、組A の戻ってきた応答が **5 本未満**（6 本中）、または組B が **16 本未満**（18 本中）なら、その切れ目は「欠け」。CR-1 の 90% の基準を 6 本・18 本にそのまま当てると 6/6・17/18 で、1 本の失敗で問題全体が外れるため、事前にこう決める。
- 欠けた切れ目が 1 つでもある問題は、主の分析から外す（CR-1 と同じ）。欠けは補わない。
- 外れた問題が N の 10% を超えるか、外したあとの問題が N_MIN 問未満なら `INCOMPLETE_NO_CONFIRMATORY_VERDICT`（CR-1 の形。70 を N_MIN に読み替える）。
- **欠けの報告**（レビュー v6 の止めない点 3）：欠けた応答の数と欠けた切れ目の数を、段（探す・確かめる）・切れ目の位置・深さの層ごとに必ず報告する。
- **探す段の欠け**：探す段の切れ目で、戻ってきた応答が **28 本未満**（32 本中）なら、その切れ目は欠け。欠けた切れ目は、2 回の出し直しのあとも 28 本に届かなければ、その問題の探す段を止め、その問題は確かめる段に進まずに外す（外れた問題に数える）。28 本以上あれば、戻ってきた本数で q̂ を出す。
- 参考：CR-1a の G2 では、226,704 件がすべて成功し、出し直しは 0 件だった。第5版のときの仮定の計算（各応答の最終成功率 99.5%、16 切れ目）では、1 問のすべての切れ目がそろう確率は、CR-2 の基準で約 99%（Claude の計算）、6/6・17/18 の基準では約 58%（レビューの計算。Claude も同じ値を確かめた）。どちらも仮定で、予測ではない。
