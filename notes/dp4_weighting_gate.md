## ひとことで（数式なしの要約）
- DP3 の主1（重みづけ）は、向きは予想どおりだった（+0.14）。ただ、事前に決めた余白に届かず「決めきれない」で終わった。
- 原因は、「実際の落ち幅」d の測り方がとても不安定だったこと。32本を16本ずつに分けて測り直すと、半分どうしの相関はほぼ0だった。
- DP4 は、**d を別の引き方で測って、雑音を大きく減らす**。

  d は「t の語が土台の語**以外**になる確率（1 − p1）」×「土台の語以外になったときの答えの変わりやすさ」に分けられる。前半の確率は、モデルの出力から**正確に**分かる。そこで後半だけを引き直しで測ればよい。後半を測るときは、最初の1語を「土台の語以外」から引く。迷いの小さい位置では、前半の確率がほぼ0なので、d の雑音もほぼ0になる。
- あわせて、DP3-X1 の事後の発見を**事前登録で確かめ直す**。その発見は「エントロピーは、2番目の候補の影響が大きい位置を逆向きに指す」（0.415）というもの。
- 扱うのは算数の問題だけ。危ない内容はない。問題の中身は表示しない。

## 定義（位置ごと。DP3 と同じ土台・同じ採点）
1. **土台の道**：DP3 と同じ（OLMo-2 1B、貪欲法、最大512トークン、同じプロンプト・採点、答えの先頭 a）。各位置で、エントロピー・p1・p2・1位と2位の語・数字かどうかを記録する（**p1 を新しく記録**）。
2. **調べる位置**：t = 0, s, 2s, …（t < a）。s は［決定3］。
3. 各位置 t で、温度1.0の純粋なサンプリングで、次の4種類を K 本ずつ引く（K は［決定2］）：
   - **keep**（DP3 と同じ）：t の語まで含めて引く → 答えが土台と違う割合 q_keep(t)。
   - **swap**（DP3 と同じ）：t の語を2番目の候補に入れ替えて引く → q_swap(t)。
   - **alt（新しい）**：t の位置の**最初の1語だけ**、土台の語（1位）を除いた分布（残りの確率を足して1になるように直したもの）から引き、そのあとはふつうに引く → q_alt(t)。
   - **free**（DP3 と同じ、確認用）：t の手前から、ふつうに引く → q_free(t)。
4. 量：
   - **層別の落ち幅** d_s(t) = (1 − p1(t)) × (q_alt(t) − q_keep(t))。free と同じものを測っている（期待値が等しい）が、雑音がずっと小さい。
   - **別の候補の影響** e_alt(t) = q_alt(t) − q_keep(t)（2番目に限らず、土台の語以外が来たときの影響）。
   - **2番目の候補の影響** e(t) = q_swap(t) − q_keep(t)（DP3 と同じ）。
   - 確認用：d_plain(t) = q_free(t) − q_keep(t)（DP3 の d と同じ）。
5. **ラベル**：d_s、e_alt、e それぞれの上位 R%（R は DP3 と同じ 15%。同点は行の小さい順、位置の小さい順）。

## 問い（主）
- **主1（重みづけ）**：位置 t のエントロピーの問題内AUROC を「d_s の上位」と「e_alt の上位」で比べる。差（d_s − e_alt）。

  d_s と e_alt の違いは「(1 − p1) をかけたかどうか」だけなので、重みづけの効果だけを取り出せる。

  ただし、(1 − p1) はエントロピーと強く結びついている。だから「d_s の上位をエントロピーが見分けやすい」こと自体は、ある程度は計算の上で予想できる。それでも、e_alt がエントロピーと強く逆向きなら、かけ算しても差は出ない。だからこれは、データで決まる問いである。
- **主2（逆向き、DP3-X1 の確認）**：位置 t のエントロピーの、「e の上位」に対する問題内AUROC が 0.5 より小さいか。
