## 0. この実験で何を確かめるか（と、確かめないこと）

CR-4 で分かったこと：CR-2 で 18 本中 1 本も揺れなかった 340 語のうち、32 本引いて別の単語が見つかったのは 30 語。そのうち 3 語は、別の単語を書かせると答えが変わりやすい単語（隠れた分かれ道）だった（ホルムのあとに残った数 H = 3）。残りの **310 語は 32 本でも 1 本も揺れず、書かせる別の単語がないので試していない**。

CR-5 は 2 つのことをする。

1. **探し直し**：310 語すべてで、新しく 16 本ずつ引いて別の単語を探し（発見）、見つかった単語では CR-4 と同じ手順で書かせて確かめる。
2. **確かめ直し**：CR-4 の分かれ道 3 語（ホルムで残った）と、ゆるい補正（ベンジャミーニ・ホッホベルグ q = 0.10）でだけ残った 3 語を、**新しく引いた応答だけで**確かめ直す。

- **見込み（データを見る前、正直に）**：CR-4 の「32 本中に揺れた本数」の分布（0 本 310 語、1 本 14、2 本 8、3 本以上 8）に 2 つの単純なモデル（ベータ二項、ゼロの多いベータ二項）を当てはめると、16 本足して別の単語が見つかる語数は **5〜6 語**の見込み。CR-4 で見つかった単語の約 1 割が分かれ道だったので、新しく確かめられる分かれ道は **0〜1 語**くらいの見込み。大きな収穫は期待しにくく、結果は「何本引くと何語見つかって、何割が効くか」という形で書く。
- **確かめないこと**：別の問題・別のモデルへの一般化（同じ 90 問・同じ 604 語）。48 本（CR-4 の 32 本 + CR-5 の 16 本）引いても別の単語が見つからなかった単語は試さない（数を報告する。「隠れた分かれ道がない」とは書かない）。
- 案 A を選んだ理由（オーナーとのやりとり）：深さ 4〜5 に絞る案は CR-4 の結果（分かれ道 3 語がすべて深さ 4〜5）を見てから出てきたもので、偶然の偏りを追いかける危険があるため、全 310 語を同じ本数で探す。

## 3. 問いとラベル

- **問R（主。CR-4 の分かれ道は、新しい応答でも分かれ道か）**
  - 対象：H3 の 3 語。
  - 値：各単語で RA1 と RU の「変わった」本数を 2×2 の表にし、片側のフィッシャーの正確検定（RA1 のほうが変わりやすい向き）の p。3 語を 1 つの家族としてホルム（0.05）。残った数 R_H。
  - ラベル：3 語のうち 1 語でも NA → `QR_INCOMPLETE`。R_H = 3 → `FORKS_REPLICATED`。R_H = 1〜2 → `FORKS_PARTLY_REPLICATED`。R_H = 0 → `FORKS_NOT_REPLICATED`。
  - 読み方：REPLICATED は「CR-4 の分かれ道は、新しく引いた応答だけでも確かめられた」。NOT は「この本数では確かめ直せなかった」（CR-4 の結果を打ち消すとは書かない。ただし CR-4 の判定が偶然だった可能性を添える）。
- **問B（主。ゆるい補正でだけ残った単語は、新しい応答で分かれ道と確かめられるか）**
  - 対象：B3 の 3 語。値・検定は問R と同じ（3 語でホルム）。残った数 R_B。
  - ラベル：1 語でも NA → `QB_INCOMPLETE`。R_B ≥ 1 → `BH_ONLY_FORKS_CONFIRMED`（R_B を書く）。R_B = 0 → `BH_ONLY_FORKS_NOT_CONFIRMED`。
- **問D（主。探し直しで、新しい隠れた分かれ道は確かめられるか）**
  - 対象：g_F が定義される T5 の単語すべて（予算で外れた単語・欠けた単語は入れない）。
  - 値：CR-4 の問2 と同じ（片側のフィッシャー + T5 の中でホルム 0.05）。残った数 H5。
  - ラベル（上から順に）：
    1. 発見の切れ目の欠けが NW0 の 10% を超えた、または T5 の単語のうち g_F が NA になったものが T5 の 10% を超えた → `QD_INCOMPLETE`。
    2. 対象が 0 語で、a1 が見つかった単語もない → `NO_NEW_ALTERNATIVES`。
    3. 対象が 0 語で、a1 が見つかった単語はあるが予算ですべて外れた → `NO_TESTABLE_ALTERNATIVES_BUDGET`。
    4. H5 ≥ 1 → `NEW_HIDDEN_FORKS_FOUND`（H5 を書く）。H5 = 0 → `NEW_HIDDEN_FORKS_NOT_DETECTED`。
  - `QD_INCOMPLETE` のときも H5 などの数は結果に残るが、記述だけで確証には使わない（結果のノートにそう書く）。
  - CR-4 の問2 にあった下限（20 語）は置かない：見込みは 5〜6 語で、フィッシャーの正確検定とホルムは語数が少なくても誤検出の割合を守る（10. で確かめる）。語数が少ないので、NOT_DETECTED は「この数・この厳しさでは確かめられなかった」と書く。
- 問R・問B・問D は別々の問いで、まとめた主張はしない。補正はそれぞれの家族の中のホルムだけ。
- **読めない応答の感度（各問い）**：読めない応答は「変わった」に数えるので、A1・RA1 にだけ読めない応答が増えると偽の分かれ道が出うる。各問いで、読めない応答を除いて数え直した残る数（`H_readable_only`）も出し、ラベルの数と違えばその問いに `QR_READOUT_SENSITIVE`・`QB_READOUT_SENSITIVE`・`QD_READOUT_SENSITIVE` を添える（ラベルは変えない）。
- **読み方の注意**：
  - 問D で U(v) を使い回す単語は、U が以前（CR-3・CR-4 の段B1）に引いた応答で、A1 は今回引いた応答になる。時間をおいたずれが上向きなら偽の分かれ道に寄るので、S4 の q_O のずれ（6 語）と並べて書く。
  - S4 の g_R − g_CR4 は、CR-4 で p の小さい単語を選んでいるので、平均への回帰で小さく出るのが当たり前であることを添える。

### ラベルの優先順（最初に当てはまったもので止める）

1. 段A・段B1・段B2 の前の照合で止まった → `STOPPED_BEFORE_RUN`（どこで止まったかを書く）。
2. 未完了 → `INCOMPLETE_NO_CONFIRMATORY_VERDICT`：予算で止まった、終わりの状態が分からないリクエストがある。段B1 が予算で止まったら段B2 は送らず、Claude が段B1 の要約からこのラベルを記録する（段C は回さない）。欠けたデータはその問いだけを未完了にする（問D は `QD_INCOMPLETE`、問R・問B は `..._INCOMPLETE`）。
3. 監査の失敗 → `PROTOCOL_AUDIT_FAIL_NO_CONFIRMATORY_VERDICT`。
4. 読めない応答 > 20%（CR-5 で新しく引いた全応答）→ `READOUT_UNRELIABLE_NO_CONFIRMATORY_VERDICT`。5〜20% はすべてのラベルに `READOUT_CAVEAT`。
5. それ以外 → 問R・問B・問D のラベルを出す（`LABELS_ISSUED`）。
