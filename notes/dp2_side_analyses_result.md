## A. 検出力のシミュレーション（作りもののデータ）

コード：`scripts/dp2_power_sim.py`（種 202610061702）。凍結したDP2の統計（`d2.metrics`・`d2.probe_oof`・`d2.label_m1`・`d2.label_m2`）をそのまま使用。
集計：`reports/dp2_side_A_power.json`（元の結果：sim_m1.json sha256 `ce317f96…`、sim_m2.json sha256 `9aecf2d8…`）。

### 主1（エントロピー）：ラベルはよく働く
- 区間の幅（両側95%）の中央値は 0.05〜0.12（分かれ道の割合 π が大きいほど狭い）。推定値の平均は真の値とほぼ一致（偏りなし）。
- 真の問題内AUROCごとのラベルの割合（π = 0.10 / 0.20 / 0.30）：
  - 0.50 → WEAK 92% / 99% / 100%
  - 0.55 → WEAK 40% / 63% / 80%（残りは MODERATE）
  - 0.60〜0.70 → ほぼ全部 MODERATE（STRONG は 0.70 でも 1〜2%）
  - 0.75 → STRONG 43% / 72% / 89%
  - 0.80 → STRONG 95% / 100% / 100%
- 読み方：STRONG（下限 ≥ 0.70）は、真の値がおよそ0.75以上でないと出ない。ゲートの予想（0.60〜0.70 → MODERATE）はこの検出力で区別できる。

### 主2（隠れ状態の上乗せ）：ラベルは「前触れなし」側に偏りうる（重要な注意）
- 隠れ状態を2048次元のばらばらな雑音（信号は1方向だけ）とすると、信号がなくても（γ = 0）上乗せは平均 −0.11〜−0.12。雑音の次元が安い特徴量を薄めて、プローブが安い特徴量だけより悪くなる。
- そのため、γ = 0〜0.3 では 82〜100% が `NO_PRECURSOR_BEYOND_CHEAP`。単独でAUROC約0.76の強い方向（γ = 0.5）があっても、`PRECURSOR_SEEN` は 0%（UNDECIDED が 12〜40%）。
- **ただし、これは最悪の場合の作り方。** 実際の隠れ状態は、安い特徴量の情報（位置・エントロピーなど）をすでに含み、ばらばらな雑音ではない。DP1-X2（実データ、同じ12層・同じプローブ設定）では「隠れ状態＋安い − 安い」は問題内で +0.022 で、−0.12 のような薄まりは出ていない（`reports/dp1x2_1B_RESULT.json`、`incremental_P0cheap_vs_cheap`）。
- 結論として書けること：主2が `NO_PRECURSOR_BEYOND_CHEAP` になっても、「前触れが存在しない」とまでは言えない。「この（凍結した）プローブでは、安い特徴量に上乗せが見えなかった」に留める。`PRECURSOR_SEEN` が出た場合は、この保守的な検定を越えたので強い証拠になる。

## B. DP1の確認用データ（S5）で見た予告編（事後）

コード：`scripts/dp2_side_b_s5.py`（ブートストラップの種 202610061701）。DP1の行ファイル20個をDriveから読み、DP1の実行の版（コード `9e896e1`・問題の集合のハッシュ `18becaa5…`）で封筒を検証してから計算した。問題の中身は表示していない。
結果：`reports/dp2_side_B_dp1s5.json`。20問 × 20か所 = 400か所。

- **B1：土台の語を選んだあとも、答えはかなり揺れる。** 8本のうち答えが土台と違う割合 q の平均は 0.35。土台が正解の12問では 0.15、不正解の8問では 0.64。後ろの位置ほど少し下がる（相対位置とのスピアマン −0.22）。q = 0 の位置は 38%、q ≥ 0.5 の位置は 37%。
  - DP2への含み：不正解の問題では q が最初から高いので、段差（d ≥ 0.25）が出やすい・出にくいが問題ごとに大きく違うはず。問題内AUROCにしたのは正しい。
- **B2：この定義（2番目の候補を選ぶと、答えが変わる割合が0.25以上増える）では、エントロピーは逆向き。**
  - 分かれ道は 16.5%（66か所、両方の種類を持つ問題17）。
  - エントロピーの問題内AUROC 0.44 [0.37, 0.50]、p2 は 0.42 [0.36, 0.48]。
  - 同じ位置での貪欲法の分かれ道（DP1の定義）に対しては、エントロピー 0.39 [0.31, 0.49]、p2 0.35 [0.27, 0.43]。
  - 読み方：2番目の候補に入れ替える定義では、迷いが小さい位置（2番目の候補がありえない語）ほど、入れ替えると答えが崩れる。DP1と同じ傾向。DP2の定義（入れ替えなし。サンプリングだけで q が段差で下がる区間）は、この人工的な効果を含まないので、DP2の主1はこれとは違う答えになりうる。
- **B3：2つの定義はあまり重ならない。** 両方が分かれ道 28、サンプリングだけ 38、貪欲法だけ 51、どちらでもない 283。
- 限界：位置はランダムな20か所で、q の「段差」は作れない。8本なので粗い。事後の探索。

## C. 関連研究

`notes/dp2_related_work.md` にまとめた（15本＋補助6本）。いちばん大事な点は次の2つ。
- **Zur, Geiger, Lubana, Bigelow（arXiv:2511.04527, 2025）**：サンプリングで決めた「結果の分布」を、中間層の線形プローブで予測できると報告済み。DP2の主2を「隠れ状態に分かれ道の情報がある」とだけ言うと新しさがない。DP2の差分は、分かれ道の**位置**を当てること、安い特徴量（位置・数字・エントロピー・p2）への**上乗せ**を測ること、**問題内**で比べること、事前登録。本文で、エントロピーを比較相手にしているかを投稿前に確認する。
- **Cliff Tokens（Ko, Kang, Lee, arXiv:2606.25524）**：64本のサンプリングで「正解に届く確率」の急落を定義し、エントロピーで分類（低エントロピーの急落もある）。1B級のモデルも含む。隠れ状態のプローブはない（arXivのページで直接確認）。
- 動機として使える食い違い：Wang ほか（"Beyond the 80/20 Rule", NeurIPS 2025）は「高エントロピーの語＝分かれ道」を仮定し、数式の部分は低エントロピーとする。DP1では、入れ替えの分かれ道は数字に集中した。DP2はこの仮定を直接確かめる。
