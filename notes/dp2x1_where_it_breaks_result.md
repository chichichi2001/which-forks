- 再現：CPU でも全部の問題での値は 0.417（DP2 の GPU では 0.420）。
- 並べ替え 200 回：偶然の 95% 点 0.293、観測 0.417、p = 0.020。
- 崩れる位置と難しさ q(0) の相関は **0.752**。崩れる位置と答えの位置 a の相関は 0.457。隠れ状態は a も当てる（0.433）。
- 落ち幅がどこにもない問題 8、崩れる位置が 0 の問題 11。
- 計画の目安：`UNCLEAR`（(i)・(ii) の値が −0.12・−0.11 で、目安の「0 付近（±0.1）」をわずかに外れたため）。

## 読み方
- **「どこで崩れるか」の予測は、ほぼ「どれだけ崩れやすいか」の予測だった。** 崩れる位置は難しさ q(0) と強く結びついていて（0.75）、分かれ道がある問題だけにしても、難しさの分を引いても、隠れ状態の予測は 0 付近（どちらもわずかに負、区間は 0 をまたぐ）まで落ちた。計画で「一番あやしい」とした説明1で、ほぼ説明できる。
- 目安のラベルは `UNCLEAR` だが、これは −0.12 が目安の線 ±0.1 をわずかに外れただけ。中身としては「位置の情報は見えなかった」と読むのが正直。
- 並べ替えで p = 0.02 だったのは、全部の問題での予測（＝難しさの予測）が偶然ではない、という意味で、「位置」を知っていることの証拠にはならない。
- DP2 の結果ノートの S2 の書き方（「どの区間で一番大きく落ちるかが当たる」）には、この注意を足す。
- 事後のおまけ（主張しない）：分かれ道がある 35 問では、安い特徴量（問題文の長さなど）が崩れる位置と負の相関（−0.51）。長い問題ほど早めに崩れる、という傾向かもしれない。問題数が少なく、事後に見つけたものなので、仮説として棚に置くだけ。
