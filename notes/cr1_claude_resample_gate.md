## ひとことで（数式なしの要約）

- DP3〜DP7 は、中身（確率）が見えるオープンモデルでやった。引き直すと答えが変わる位置（引き直しの分かれ道）は、迷いの大きい位置とよく重なった（論文の表 2）。
  ただしその重なりの大部分は、「別の語が引かれる確率」という重みから出てくるものだった（論文 3.2 節）。
- CR-1 では、**確率が見えない商用モデル（Claude Haiku 4.5）**で、同じことを外から測る。
  - トークンは見えないので、**単語の区切り**で切る。
  - 迷いは、**同じ場所から何本も引き直して、続きの出だしがどれだけばらつくか**で測る。
- 落とし穴（第5版で対処）：別の単語が引かれやすい場所ほど、**差が本当はなくても**、引き直しの偶然の揺れで落ち幅が大きく見えやすい。
  そういう場所を上位から選ぶと、ばらつきも同じ場所で大きいので、差がなくても好成績に見えうる。
  → 陰性対照を事前に組み込む。同じ切れ目の中で「答えが変わった」の印を、別の単語を引いた続きとそのまま書いた続きのあいだで入れ替える**並べ替えの検定**。
- 「差がない」には 2 種類あり、別のものとして扱う（第6版）：
  - **入れ替えの仮説**（主1 の陰性対照が調べるもの）：同じ切れ目から引き直した続きのうち、次の単語を**そのまま書いたもの**と**別の単語を引いたもの**で、答えの変わりやすさが同じ。
  - **プリフィル比べの差 g**（主0 が調べるもの）：別の単語を引いた続きと、**次の単語までをプリフィルで固定して引き直した続き**の、答えの変わりやすさの差。
  - 「そのまま書いた」続きと「プリフィルで固定した」続きは、同じ文字列から始まっても同じ振る舞いとは限らない。この 2 つの食い違いは残り r として測る（C1）。
  - どちらの差も、引き直した続きの中での**結びつき**で、「その単語を書かせたせいで答えが変わった」という因果の主張はしない。
- 確かめること：
  0. そもそも、別の単語を引いた続きは、プリフィルで固定した続きより答えが変わりやすいか（信号の確認。プリフィル比べの差 g）。
  1. 外から測ったばらつきは、引き直しで決めた相対的な分かれ道を見分けるか。そしてそれは、入れ替えの仮説のもとで出る点数を超えるか。
  2. それは、差 g を並べ替えた基準と区別できるか。
  3. 相対的な分かれ道は、数字の単語に偏るか。
- 言い方の約束：
  - よい結果でも「論文の結果が Claude で再現した」とは言わない。言えるのは「外から測れる代わりの指標がある（またはない）」まで。
  - 分かれ道のラベルは、層に分けた落ち幅 d_s の**有限の引き直しによる推定値**で決めた、操作的で相対的なラベル。「本当の分かれ道」とは呼ばない。d_s が d の代わりになるとも主張しない。
  - 主1 で陰性対照を超えなければ、「u は推定値の上位の位置を見分けたが、それは入れ替えの仮説のもとでも起こる程度だった」と書く。
  - 主2 で基準と区別がつかないときは、「この基準と区別できない」と書く。「重みで説明できることが証明された」とは書かない。
- 扱うのは算数の問題だけ。危ない内容はない。問題の中身は表示しない（数字・ID・ハッシュだけ）。

## 定義

1. **問題**：GSM-Symbolic（DP と同じ出どころ）の 100 テンプレートから、**1 テンプレート 1 問**。
   - 各テンプレートで、DP7 の除外の連鎖（Quality-Pork と DP1〜DP7 で使った問題）を外した残りから、乱数種 SEED_ITEM の順に最大 3 問まで候補にする。
   - 候補を順に見て、土台の道（定義 3）が定義 4 の条件を満たす最初の 1 問を使う。3 問とも満たさないテンプレートは使わない。
   - 使った問題の数を N とする（見込み 85〜100）。結論は、この条件で選ばれた問題の集まりについてのものである。
2. **モデルと頼み方**：モデルは `claude-haiku-4-5-20251001`（正確な ID）。思考（extended thinking）は使わない。
   - 利用者の発言として「短く考えを書いてから、最後の行に `#### <数>` の形で答えを書く」と頼む。最大 400 トークン。
   - プリフィルは、messages の最後に assistant の発言として P_c を置く形。
   - SDK（`anthropic` パッケージ）の版は G0 で入ったものを記録し、本番も同じ版に固定する。モデルや API が変わると再現できなくなることがある。
3. **土台の道**：各問題で 1 本。G0 の結果で決まる（事前に決めてある）。
   - API が `extra_body` での温度 0 の指定を受け付けるなら温度 0。受け付けないなら標準の温度 1 で 1 本。
4. **土台の道の条件**：答え（`####` の後の数）が読める。答えの行より前の単位（定義 5）が 30〜80 個。`stop_reason` が `end_turn`。
5. **単位**（P5・A5）：土台の道の文章の、最初の `####` を含む行の**行頭より前**の部分を、Python の `str.rstrip()` で末尾の空白を落としたものを T とし、Python 3 の `re`（文字列に対して。`\s` は Unicode の空白すべて）で正規表現 `\s*\S+` を先頭から当てて区切ったもの。
   - 連続した空白・改行・タブは、すべて**次の単位の先頭**に入る。T の末尾の空白は、どの単位にも入れない。
   - 単位 w の文字列を s_w、P_w = s_1 + … + s_w（P_0 は空）。実装では「全単位をつなぐと T の末尾の空白を除いたものと 1 文字も違わない」ことをテストで確かめる。
   - 1 から L まで番号をつける。
6. **切れ目 c**（c = 0, 1, …, L）：プリフィルは P_c（末尾は空白でない文字。API の決まりと合う）。c = 0 はプリフィルなし。
7. **引き直し**：各切れ目から、標準の設定（温度・top_p は指定しない）で K 本、最大 400 トークンまで書かせる。
   本番号 k = 0, 1, …, K − 1 のうち、k < K_A を**組A（迷い用）**、残りを**組B（分かれ道用）**とする。
8. **リクエストの状態**（P3）：
   - **終わった状態**：バッチの結果で、各リクエストが「成功」「エラー」「期限切れ」「取り消し」のどれかになったこと。
   - **戻ってきた応答**：「成功」のもの（`stop_reason` が `max_tokens` のものも含む）。
   - **欠け**：2 回の出し直しのあとも「成功」にならなかったもの。同じ `custom_id` で成功が 2 つ以上あれば、出した順で最初のものを使う。
   - 答えの読み取り：P_c ＋ 続き の全文から、最後の `####` の後の数を読む。読めない（空の出力、空白だけ、`max_tokens` で切れて `####` がない、など）ときは「土台と違う」に数える。`max_tokens` で切れても `####` の後の数が読めれば、それで採点する。
   - 割合の分母は、その切れ目・その組の戻ってきた応答の数。
9. **変わる割合**：q(c) は、切れ目 c からの組B の戻ってきた応答のうち、答えが土台の答えと違った割合。
10. **続きが単位 w を「そのまま書いた」**：切れ目 w − 1 からの続きの文字列が、**s_w で始まる**こと（前方一致）。
    - このとき全文の先頭は、P_w をプリフィルしたときと同じ文字列になる。ただし内部のトークンの並びまで同じとは限らないので、残り r は 0 と仮定しない。
11. **単語 w の分かれ方**（切れ目 w − 1 からの組B を、定義 10 で 2 つに分ける）：
    - n_B：組B の戻ってきた応答の数。n_diff(w)：s_w で始まらなかった数。x_diff(w)：そのうち答えが変わった数。
    - 重み m(w) = n_diff(w) / n_B。q_keep(w) = q(w)、n_keep(w) は切れ目 w の組B の戻ってきた応答の数。
    - n_same(w) = n_B − n_diff(w)：s_w で始まった数。x_same(w)：そのうち答えが変わった数。q_same(w) = x_same(w) / n_same(w)（n_same ≥ 1 のときだけ）。
    - X(w − 1) = x_diff(w) + x_same(w) は、切れ目 w − 1 の組B で答えが変わった数（q(w − 1) = X(w − 1) / n_B）。
12. **落ち幅**（本数を数えた積の形で計算するので、空の組でも定義できる）：
    - そのままの落ち幅 d(w) = q(w − 1) − q_keep(w)。
    - 層に分けた落ち幅 d_s(w) = x_diff(w) / n_B − m(w) × q_keep(w)。n_diff(w) = 0 なら 0。
    - 残り r(w) = d(w) − d_s(w)。数を数えると r(w) = x_same(w) / n_B − (1 − m(w)) × q_keep(w) で、n_same ≥ 1 なら (1 − m(w)) ×（q_same(w) − q_keep(w)）。
      つまり r は「そのまま書いた続き」と「プリフィルで固定した続き」の食い違いで、入れ替えの仮説とプリフィル比べの差 g が食い違う分そのもの（第6版、Q1）。
    - プリフィル比べの差 g(w) = x_diff(w) / n_diff(w) − q_keep(w)。n_diff(w) ≥ 1 の単語でだけ定義する。結びつきの差で、因果の効き目とは呼ばない（Q4）。
13. **相対的な分かれ道の単語**：
    - 対象は d_s(w) > 0 の単語だけ。d_s ≤ 0 の単語は、決して分かれ道にしない。
    - その実験のすべての単語をまとめて、全単語数 × 0.15 を切り捨てた個数を、d_s > 0 の単語から d_s の大きい順に選ぶ。足りなければ、d_s > 0 の単語をすべて選ぶ。
    - 境目で同じ値が並んだときは、**その値の単語をすべて選ぶ**（乱数を使わない。そのため選ぶ数が上の個数を少し超えることがある。超えた数を報告する）。
    - ラベルは全データで 1 回だけ決め、ブートストラップの中では決め直さない（論文と同じ）。
14. **外から測ったばらつき u(w)**：組A の、切れ目 w − 1 からの続きの「最初の単位」（続きの文字列の先頭に `\s*\S+` を当てたもの）について、1 −（一番多かった最初の単位の割合）。
    - 比べ方は文字列の完全一致。空の出力・空白だけの出力の最初の単位は、内部では文字列でない目印（Python の `None`）にする。どの本物の文字列とも一致しない。表示では `<EMPTY>` と書く（A5）。
15. **組A の重み（2 通り）**：
    - m_A(w)：組A のうち、続きが s_w で始まらなかった割合（定義 10 と同じ前方一致）。
    - m_A^unit(w)：組A のうち、最初の単位（定義 14）が s_w と完全一致しなかった割合（u と同じ区切り方）。
16. **乱数種**（P5）：SEED_ITEM = 202610110045、SEED_PERM = 202610110102、SEED_BOOT = 202610110103、SEED_NULL = 202610110104、SEED_AUDIT = 202610110105（SEED_TIE は第5版の途中で使わなくなった。番号 202610110101 は欠番）。組A・組B は本番号で決める（定義 7）。C2 の半分は組B の本番号の偶数・奇数で分ける。

## 確かめ（C。どれもラベルは出さない。記述だけ）

- **C1 d と d_s の関係**：r の平均（テンプレートを単位にしたブートストラップの 95% 区間）、|r| の中央値と 90 パーセンタイル、d と d_s の順位相関、d と d_s の相対的な分かれ道（定義 13 と同じ決め方）のコーエンのカッパ。
  記述だけで、「d_s は d の代わりになる」という主張には使わない。d での主1・主3 は S4。
  - あわせて、q_same − q_keep の n_same で重みをつけた平均（テンプレートを単位にしたブートストラップの 95% 区間）を出す。0 から離れているほど、主0（g）と主1 の陰性対照（入れ替えの仮説）が別のことを調べている度合いが大きい。これは CR-1 の範囲の境目として報告し、r を 0 とは仮定しない（Q1）。
- **C2 ラベルの信頼性**：組B を本番号の偶数・奇数で半分ずつに分け、それぞれで d_s を計算する。全単語をまとめて、2 つの d_s のピアソン相関 r_half を出す。
  信頼性 = 2 r_half /（1 + r_half）（スピアマン・ブラウン）。r_half ≤ 0 なら 0。どちらかの半分で全単語の d_s が同じ値なら「計算できない」。
  - 信頼性 < 0.5 なら、主1 と主3 の**すべてのラベル**に「ラベルの信頼性が低い」と添える。ラベルの雑音が AUROC をどちらに動かすかは、一般には決まらない。
  - **ラベルの一致**（A1）：2 つの半分の d_s に、それぞれ定義 13 をそのまま当てはめ、相対的な分かれ道のラベルのコーエンのカッパとジャカード係数、主1 の対象になる問題の集まりの重なり（ジャカード係数）を出す。

- **主1（外から測ったばらつきは、相対的な分かれ道を見分けるか。入れ替えの仮説のもとで出る点数を超えるか）**（P1・Q1・Q2）：

  - **陰性対照：切れ目の中の並べ替えの検定**：

      これは、同じ切れ目の同じ頼み方から独立に引いた応答どうしが入れ替え可能であることを前提にした仮説で、「2 つの組の割合が同じ」より強い。結果にもこの前提を書く（F1 のレビューの注記）。
